# Lexable Accessibility

Cursor plugin by Bertoli Studios.

Build and review accessible web interfaces with WCAG-focused rules, audits, remediation guidance, and accessibility workflows directly in Cursor.

Commands: `/lexable-login`, `/lexable-status`, `/lexable-audit`, `/lexable-fix`, `/lexable-review`.

See the repository README for installation, development mode, and limitations.

Lexable does not claim WCAG conformance from static code analysis alone.
